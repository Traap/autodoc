\subsection{Scope}
This report applies to \Gls{company} medical device software projects that
require unit testing for a \stdCfgItem, software unit, or component.  It covers
the activities and records used to determine whether the tested item satisfies
the applicable unit-level requirements, design expectations, or intended use
requirements.

\tlcVspace

The scope should identify the tested code, version, test environment, included
test cases, excluded behavior, and limitations that affect interpretation of the
unit test conclusion.
