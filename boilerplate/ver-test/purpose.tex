\subsection{Purpose}
This \stdRptPkg\ provides the controlled record for verification testing of the
identified \stdCfgItem.  It identifies the system requirements tested, the test
reports executed, the configuration used for execution, and the objective
evidence generated by each verification activity.

\tlcVspace

The record supports the verification conclusion by preserving the pass/fail
result for each test step and test report, the disposition of deviations or
anomalies, and confirmation that the \stdCfgItem\ has an approved \stdCfgID.
