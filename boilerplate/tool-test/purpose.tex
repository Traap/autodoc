\subsection{Purpose}
This \stdRptPkg\ provides the controlled record for validation of the identified
\stdCfgItem\ as a software lifecycle tool.  It identifies the tool's \stdIUR,
the test reports executed, the configuration used for execution, and the
objective evidence generated by each validation activity.

\tlcVspace

The record supports the validation conclusion by preserving the pass/fail result
for each test step and test report, the disposition of deviations or anomalies,
and confirmation that the \stdCfgItem\ has an approved \stdCfgID.
