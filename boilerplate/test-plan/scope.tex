\subsection{Scope}
This \stdTestPlan\ applies to the test activity, software configuration,
requirements, risks, and operating environment identified in this report.  It
should identify the included tests, excluded items, required tools, input data,
expected records, and any prerequisites that must be satisfied before execution.

\tlcVspace

The scope should also state whether the plan supports unit testing,
verification, validation, regression testing, tool validation, or another
controlled software lifecycle activity.
