\section{Purpose}
This is the software development plan for the identified software product or
project.  The plan identifies or references the lifecycle activities,
responsibilities, tools, reviews, deliverables, and quality controls required to
satisfy the \autodocCompanyName\ software development process.

\tlcVspace

The approved plan provides a common execution baseline for medical device
software teams and a reviewable record for quality and regulatory authorities.
It should be updated or supplemented when project changes affect planned
activities, deliverables, tools, risk controls, or acceptance criteria.
