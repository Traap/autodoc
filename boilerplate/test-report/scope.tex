\subsection{Scope}
This report applies to \Gls{company} medical device software projects that
require verification or validation testing for configuration items.  It covers
the activities and records used to determine whether the configuration items
meet applicable system requirements, user needs, interfaces, and defined
acceptance criteria.

\tlcVspace

The scope should identify the software version, tested configuration, execution
environment, referenced plans or protocols, included requirements, excluded
items, and limitations that affect the test conclusion.
